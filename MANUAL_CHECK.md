# Проверка лендинга Dear Money в вашем браузере

Лендинг собран, тексты доработаны по согласованию с автором. Макет `design/index.html` и описание `design/README.md` обновлены по согласованной странице: тексты и оформление должны совпадать.

Автоматическая проверка сохраняет скриншоты, проверяет три ссылки в приложение, два якоря, загрузку локальных шрифтов и отсутствие горизонтального переполнения. С флагом `--responsive` проверяются 10 ширин от 280 до 1440 px.

## 1. Открыть страницу

Запустите PowerShell в папке проекта и выполните:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Затем откройте http://localhost:4321/. Если сервер уже запущен, сразу откройте этот адрес. Для проверки готовой сборки вместо `pnpm dev` выполните `pnpm build`, затем `pnpm preview`. Остановить сервер можно сочетанием Ctrl+C в запустившем его окне. Сам макет по-прежнему можно открыть файлом `design/index.html`.

## 2. Проверить шрифты

Шрифты включены в папку `public/assets/fonts/` и загружаются с лендинга. Доступ к Google Fonts больше не нужен.

В Edge или Chrome нажмите F12, выберите инструмент выделения элемента и нажмите на заголовок «На важное деньги есть.». В панели Computed («Вычислено») найдите Rendered Fonts («Отрисованные шрифты»): должен отображаться **Unbounded**. Для абзаца под заголовком должен отображаться **Golos Text**.

Если видны Arial или другой запасной шрифт, проверьте загрузку CSS страницы и файлов `/assets/fonts/*.woff2` на вкладке Network («Сеть») и обновите страницу. При размещении на хостинге загружайте всю папку `dist/`, включая `_astro/` и `assets/`.

## 3. Проверить две ширины

1. На странице лендинга откройте F12 и нажмите Ctrl+Shift+M.
2. Выберите режим Responsive («Адаптивный») и ширину **393**, высоту **900**, масштаб устройства **DPR 1**. Для ширин до 600 px автоматическая проверка использует мобильную эмуляцию.
3. Обновите страницу. Через меню ⋮ панели устройств выберите Capture full size screenshot («Сделать полноразмерный скриншот»).
4. Проверьте, что заголовки, тексты и кнопки помещаются в блоки, а горизонтальной прокрутки нет.
5. Повторите захват страницы на ширине **1440** с той же высотой и DPR. Сравните с актуальным макетом `design/index.html`: тексты, оформление и высота блоков должны совпадать.

Автоматическую проверку можно повторить из второго окна PowerShell в папке проекта, оставив сервер запущенным:

```powershell
pnpm verify:design --responsive
```

Результат будет в `screenshots/report.json`. Для всех ширин должны быть `noHorizontalOverflow: true`, `allElementsFit: true`, `touchTargetsAtLeast44px: true`, `anchorWorks: true`, `appLinks: 3`, `fonts.golos: true` и `fonts.unbounded: true`. Поля `referenceFonts.golos`, `referenceFonts.unbounded`, `identicalScreenshots` и `textMatches` также должны иметь значение `true`. Скриншоты страницы `landing-<ширина>.png` и макета `reference-<ширина>.png` находятся в той же папке.

## 4. Проверить переходы

- «Войти», «Начать копить» и «Создать первый конверт» открывают https://app.dearmoney.space/.
- «Как работает» и «Как это работает» прокручивают страницу к трём шагам.

Приёмка завершена, когда страница открыта в вашем браузере, оба требуемых шрифта загружены, обновлённые тексты читаются и помещаются на двух ширинах, а переходы работают.
