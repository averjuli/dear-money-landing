# Dear Money — лендинг

Статический лендинг на Astro и Tailwind CSS 4 по макету `design/index.html`. При сборке получается HTML и CSS без клиентского JavaScript, сервера и базы данных. Все кнопки входа и начала накоплений ведут на https://app.dearmoney.space/.

## Запуск

Нужны Node.js 24 или новее и pnpm 12.10.1. Версии зависимостей закреплены в `pnpm-lock.yaml`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://localhost:4321. Для другого порта: `pnpm dev --port 4322`.

## Структура и дизайн-токены

- `src/pages/index.astro` — страница с согласованными текстами.
- `src/styles/tokens.css` — единственный источник цветов, шрифтов, размеров текста, отступов, скруглений, тени и ширин рабочей страницы. Цвет вкладки браузера также берётся отсюда при сборке.
- `src/styles/global.css` — оформление через токены и примитивы Tailwind. Стандартный сброс стилей Tailwind отключён для сохранения согласованного вида.
- `public/assets/` — локальные шрифты и их лицензии; `public/favicon.svg` — значок сайта. Astro копирует их в `dist/`.
- `design/index.html` — независимый HTML-макет со своими стилями для сравнения; `design/README.md` — его описание и тексты.

Цвета в теме Tailwind названы `--color-bg`, `--color-accent` и т. п.; шрифты — `--font-body` и `--font-heading`. Числовые отступы обозначают пиксели: например, `--spacing-24` равен `24px`. Адаптивные значения имеют отдельные имена, например `--spacing-page` и `--text-hero`. Новые значения оформления добавляются в `tokens.css`, затем используются в стилях через переменные или классы Tailwind.

## Сборка

```sh
pnpm build
pnpm preview
```

Предпросмотр сборки доступен на http://localhost:4321. Содержимое `dist/` предназначено для статического хостинга: Node.js на сервере не нужен. Шрифты Golos Text и Unbounded включены в `public/assets/` и загружаются локально. Файлы взяты из сборки приложения Dear Money; обращения к Google Fonts не требуются.

Страница адаптируется к ширине окна: карточки переходят в одну колонку, мокап сжимается вместе с контейнером, а основные кнопки на телефоне занимают всю доступную ширину.

Инструкция для проверки в браузере: [MANUAL_CHECK.md](MANUAL_CHECK.md).

Проверка адаптивности, ссылок и якорей на ширинах 393 и 1440 в установленном Microsoft Edge:

```sh
pnpm verify:design
```

Полная проверка ширин 280, 320, 360, 375, 393, 430, 600, 768, 1024 и 1440 px:

```sh
pnpm verify:design --responsive
```

Предварительно запустите `pnpm dev` или `pnpm build` и `pnpm preview`. Скриншоты и отчёт сохраняются в `screenshots/`. Проверяются выход элементов за границы окна, горизонтальная прокрутка, высота ссылок не менее 44 px, загрузка локальных шрифтов, ссылки и якоря, точное совпадение текстов и PNG с макетом. Проверка сама запускает временный локальный сервер только для макета и его ресурсов; в сборку макет не входит. Для другого адреса страницы задайте переменную окружения `PREVIEW_URL` в текущем терминале, без создания `.env`.

## Выкатка

После однократной настройки доступа push в `main` запускает [Deploy landing](https://github.com/averjuli/dear-money-landing/actions/workflows/deploy.yml):

1. GitHub Actions устанавливает закреплённые версии зависимостей и собирает `dist/`.
2. `rsync` загружает содержимое `dist/` в `/var/www/dearmoney.space` на сервере `153.76.175.28` и удаляет из этой папки файлы прежней версии, которых больше нет в сборке.
3. Уже настроенный nginx отдаёт сайт по адресу https://dearmoney.space. На сервере ничего не собирается.
4. Workflow сравнивает номер опубликованного коммита в `/deployment.txt` с текущим коммитом и проверяет ответ главной страницы: HTTP 200.

Для следующей версии достаточно сохранить изменения, сделать коммит и push в `main`. Дождитесь зелёного результата в Actions. При ошибке откройте красный прогон: он покажет, на каком шаге остановилась выкладка. После исправления сделайте новый коммит и push. Автоматического отката нет.

Приватная часть отдельного ключа деплоя хранится только в секрете GitHub `LANDING_DEPLOY_SSH_KEY`. Его публичная часть — `deploy/deploy_key.pub`. На сервере этот ключ относится к пользователю `dear-money-landing` и разрешает только загрузку через `rrsync` в папку лендинга. Ключи приложения и его папки не используются для выкладки лендинга. Доверенные публичные ключи самого сервера закреплены в `deploy/known_hosts`.

Однократную настройку выполняет администратор через `sudo bash deploy/install-on-server.sh` рядом с файлом публичного ключа. Скрипт проверяет существующую заглушку, создаёт отдельного пользователя и даёт ему доступ к папке лендинга. Конфиги nginx, приложение и существующие SSH-ключи он не меняет. Пароль `sudo`, если он нужен, администратор вводит только в своём терминале.
