# Dear Money — лендинг

Статическая страница на основе `design/index.html`: HTML и CSS, без зависимостей и клиентского JavaScript. Тексты доработаны по согласованию с автором: конкретнее польза, короче три шага, пояснение о ручном учёте денег, сравнение и финальный призыв. Все кнопки входа и начала накоплений ведут на https://app.dearmoney.space/.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Откройте http://localhost:4173. Порт можно изменить переменной окружения `PORT`.

## Сборка

```sh
npm run build
npm run preview
```

Содержимое `dist/` можно разместить на любом статическом хостинге. Шрифты Golos Text и Unbounded включены в `assets/` и загружаются локально. Файлы взяты из сборки приложения Dear Money; обращения к Google Fonts не требуются.

Страница адаптируется к ширине окна: карточки переходят в одну колонку, мокап сжимается вместе с контейнером, а основные кнопки на телефоне занимают всю доступную ширину.

Инструкция для проверки в браузере: [MANUAL_CHECK.md](MANUAL_CHECK.md).

Проверка адаптивности, ссылок и якорей на ширинах 393 и 1440 в установленном Microsoft Edge:

```sh
node scripts/verify-design.mjs
```

Полная проверка ширин 280, 320, 360, 375, 393, 430, 600, 768, 1024 и 1440 px:

```sh
node scripts/verify-design.mjs --responsive
```

Предварительно запустите `npm run dev`. Скриншоты и отчёт сохраняются в `screenshots/`. Проверяются выход элементов за границы окна, горизонтальная прокрутка, высота ссылок не менее 44 px, загрузка локальных шрифтов, ссылки и якоря. Обновлённые тексты намеренно отличаются от исходного макета; равенство PNG не является условием прохождения проверки. Флаг `--compare-original` включает строгое сравнение со старым макетом и ожидаемо завершается ошибкой на обновлённом тексте.
